# Provenance and qualification

The numeric engine, its 16 tests, rendering builder, DOM shim and v0.2 vocabulary were recovered from the user's prior RIPO computation work of 2026-10-31, associated with JUN-654. The authored additions and successive patches were reconstructed in order from the originating computation chat. No private Library link, credentials, chat transcript or managed configuration is included here. The original calculation outputs were not imported as fresh evidence: all included results are generated again locally.

`engine.VERSION = 0.2.0` names the recovered numeric algorithm. `ripo.snapshot-extraction.v0.3` names the new standalone input/output profile and does not imply that all research proposals are implemented. SHA-256 in these files identifies canonical JSON under the stated recipe, not an IPLD block. Git commits identify source revisions; neither establishes empirical truth.

The numeric model is a Python scientific reference. It is not part of the Kotoba build/runtime/CI closure, a native gate, or a production service. The existing Kotoba/IPLD/DAG-CBOR/CID architecture motivates a future persistence adapter; it has not been connected to this engine. No CI workflow, automatic publication, app-origin API or network request is added. The browser viewer is a static offline artifact.

The earlier v0.2 statement that RDF expansion was untested is historical. This repository adds explicit RDF parsing and bounded SHACL tests; it still does not claim OWL consistency, BFO/CCO alignment, Inc equivalence, a formal proof of the finite optimizer or real-data validity. The global search enumerates partitions at at most eight observations. Six synthetic cases and a known toy intervention model are fixtures, not measurements of living or social systems.
